# Contact Management System

Full-stack Contact Management System built with Spring Boot, React, and SQL Server.

## Features

- User registration and login
- JWT authentication
- Contact CRUD operations
- Contact search and pagination
- Email and phone management
- User profile and password management
- CSV contact import and export
- Responsive React dashboard
- SonarQube code quality analysis

## Technologies

### Backend
- Java 21
- Spring Boot
- Spring Security
- JWT
- SQL Server
- Maven

### Frontend
- React
- Vite
- React Router
- JavaScript
- CSS

## Code Quality

- Backend automated tests
- Frontend ESLint and production build checks
- SonarQube Quality Gate passed
